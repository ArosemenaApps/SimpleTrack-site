# Simple Track — website

The public site for **Simple Track - Calorie Log**: the privacy policy and support
page App Store Connect links to.

- `index.html` — landing page
- `privacy.html` — privacy policy
- `support.html` — support page
- `style.css` — the only stylesheet; the site fetches nothing from anywhere else

Served by GitHub Pages from `main` at the repository root.

## Keeping it honest

The privacy policy has to match what the binary actually does. When app behaviour
changes, update `PRIVACY.md` in the app repository and this page together — the App
Store privacy answers are generated from the same facts, and all three must agree.
